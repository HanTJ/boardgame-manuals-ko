# 보드게임 한국어 매뉴얼

공식 규칙서를 기준으로 정리한 비공식 한국어 보드게임 매뉴얼 모음입니다.

## 등록된 게임

- [Tacoloco](./games/tacoloco/) — Helvetiq, 2025
- [Monopoly Deal](./games/monopoly-deal/) — Hasbro, B0965 계열 영문판

## 디렉터리 구조

```text
.
├── index.html                 # 매뉴얼 목록
├── styles.css                 # 공통 디자인 및 인쇄 스타일
└── games/
    ├── tacoloco/
    │   └── index.html
    └── monopoly-deal/
        └── index.html         # 게임별 한국어 매뉴얼
```

새 게임은 `games/<영문-슬러그>/index.html`에 추가하고 루트 `index.html`의 목록에 연결합니다.

## 로컬 확인

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 번역 원칙

1. 출판사 또는 디자이너가 제공한 공식 규칙서를 최우선 출처로 사용합니다.
2. 원문에 없는 규칙은 추가하지 않습니다.
3. 애매한 문장은 보조 출처와 실제 구성물을 대조합니다.
4. 각 페이지에 공식 원문 링크, 출판사와 권리 고지를 표시합니다.
5. 수정 시 게임의 판본과 최종 확인일을 함께 갱신합니다.

## 권리 안내

이 저장소의 한국어 문서는 플레이 편의를 위한 비공식 팬 번역·요약입니다. 게임명, 규칙, 삽화 및 기타 게임 관련 권리는 각 원저작자와 출판사에 있습니다. 권리자의 요청이 있으면 해당 콘텐츠를 수정하거나 내립니다.
